# eye

one chrome extension that sees everything. grab any media or piece of a site, keep it in your bin, send it to storyboardmore or brn, hand it to an agent, edit any page, map every page a site has

## what you can do

- **grab** hover any picture or video, bin · ask · send. highlight text for the same. ⌥⇧M picks a bunch at once
- **bin** everything you grab stays in the side panel even after you leave the page
- **send** to a storyboardmore board or brn admin
- **ask the agent** claude code on your mac does whatever you ask about the page, the media, the whole site (needs eye-helper from the chrome extensions repo running)
- **pick code ⌥⇧C** click anything and get its html, edit it live
- **eye mode ⌥⇧E** the whole page is editable, type over it, drag stuff, remove stuff
- **map** every page a site has, links, sitemap, hidden js routes, api paths, and check which ones open

## install

chrome → extensions → developer mode → load unpacked → this folder. ⌥⇧Y opens the panel, sign in from settings
